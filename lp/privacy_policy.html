プライバシーポリシー

遠藤拓弥（以下「当社」）は、以下のとおり個人情報保護方針を定め、個人情報保護の仕組みを構築し、全従業員に個人情報保護の重要性の認識と取組みを徹底させることにより、当社の提供するウェブサイト、スマートフォンアプリ（以下、「当社サービス」）の利用者（以下、「ユーザ」といいます）の個人情報の保護を推進いたします。

■ 取得する情報

  • ユーザから提供を受けた情報、又はユーザの許可を得て取得した情報：ユーザが当社サービス内の特定の機能を利用する場合又はユーザの情報を当社サービスに登録する場合、年齢、性別、地域等の一定の情報をご提供いただくことがあります。ユーザからお問い合わせがあった場合、ユーザの氏名、連絡先（メールアドレス、電話番号等）をご提供いただくことがあります。
  • ユーザの当社サービス利用に関する情報：当社は、ユーザが当社サービスをどのように利用しているかに関する情報（Cookie、広告識別子、ユーザが当社サービスでご覧になるページ、それらのページでの滞在時間、ユーザがクリックした当社サービス上のリンク（広告を含みます）に関する情報、その他の統計等に関する情報）を自動的に取得します。
  • ユーザの端末から送信される情報：当社は、当社サービスのご利用時にユーザの携帯端末から送信される情報（ユーザ設定やOS名等）を取得します。
  • 外部パートナーからの情報：当社は、広告主や媒体その他の外部パートナーからユーザに関する情報（年齢、性別、利用地域等）を受け取ることがあります。

■ 個人情報の管理

当社は、ユーザの個人情報への不正アクセス・紛失・破損・改ざん・漏洩などを防止するため、セキュリティシステムの維持・管理体制の整備・社員教育の徹底等の必要な措置を講じ、安全対策を実施し個人情報の厳重な管理を行ないます。

■ 個人情報の利用目的

  • 当社サービスの提供、改良、開発：当社は、取得した情報を、当社サービスの運営、提供、維持、保護、評価及び改善、新しいサービスの開発、ユーザ及び当社の権利利益の保護のために利用いたします。そのような利用には、アンケートの実施や情報の分析、最適な広告配信も含まれます。
  • ユーザとのコミュニケーション：当社は、ユーザの情報を、当社サービスに関するご案内などのマーケティングコミュニケーション、ポリシーや規約に関するお知らせのために使用します。また、ユーザからの問い合わせに返信するためにも使用します。

■ 広告配信に関する情報

当社サービスは、広告配信について下記の外部サービスを利用しております。

  • Google AdMob：Google社のGoogle AdMobは、ユーザーからユーザープロパティ及び表示された広告に関する一定のトリガーがあった場合におけるイベントの情報をGoogle社に提供します。Google社は、これらの情報をもとに、Google AdMobを実装するアプリにおいて、ユーザーとの関連性の高い内容の広告を選択して表示します。

■ 利用者動向の測定に関する情報

当社は、当社サービスの向上のため、Google社のGoogle Firebase、Google Firebase Crashlyticsを利用しての当社サービスの利用者動向の計測を行っています。データ取得のためにGoogle社が独自のIDを設定し、または既存のデバイスIDを読み取る場合があります。その際、Google社に対して、お客様が操作した内容やIPアドレスなどの情報を自動的に送信します。

■ AI機能（AI文字起こし・議事録）で送信する情報

AI文字起こしとクラウドでの議事録作成には、Google の Gemini API を利用します。以下はこれらの機能に固有の説明です。

  • 収集方法・送信内容・目的：ユーザが選んだ録音の音声と言語設定を送信し、文字起こし、話者の区別、要約を作成します。クラウド議事録では、文字起こしのテキストと言語設定を送信し、要約とTODOを作成します。議事録作成の操作だけでは音声ファイルを送信しません。音声・テキストに含まれる氏名や連絡先、話している人の声、会話の内容も送信対象です。
  • 共有先・送信経路：音声は Google Cloud Storage に一時保存し、Google Cloud Run 上の当社サーバーから Google の Gemini API に転送します。テキストは当社サーバーから Gemini API に送ります。Google Firebase Authentication の匿名認証IDと認証トークンを、当社サーバーでの認証、不正利用防止、利用制限に使用します。匿名IDは音声の保存先パスにも含まれます。当社はこのIDや広告IDを Gemini の生成リクエストに追加しません。ただし、音声・テキスト内の個人情報は自動的に除去されません。
  • 選択と同意：音声送信とテキスト送信について、それぞれ送信前にアプリ内で内容、共有先、目的を説明し、「同意して送信する」または「送信しない」を選べる画面を表示します。許可は同じ機能の今後の利用（音声文字起こしのショートカットを含む）にも適用され、設定の「AI送信の許可をリセット」から今後の送信への許可を取り消せます。既に送信・処理済みのデータを取り消すものではありません。説明を更新した場合は必要に応じて再同意を求めます。同意前と拒否した場合は、該当するAI処理のための認証・アップロード・生成リクエストを開始しません。録音・再生などは引き続き利用できます。ショートカットも音声送信の同意が必要で、未同意ならアプリでの確認を案内します。
  • 端末内の処理：Apple Intelligence が利用可能な場合の議事録生成は端末内で行います。利用できない場合、テキスト送信への同意なしにクラウドへ切り替えて送信することはありません。Appleの音声認識は別の機能であり、OSの音声認識許可に従いAppleのサービスに音声が送信される場合があります。
  • 保存と削除：Cloud Storage の音声は Gemini への転送成功後に削除を要求します。失敗などで残った音声は作成から1日経過すると自動削除の対象になります。実際の削除は非同期のため、24時間以内の完了を保証するものではありません。削除された音声は7日間復元可能な状態で保持されます。Gemini Files にアップロードした音声にも処理終了時に削除を要求します。これらの削除要求は、Googleが安全性確保などのために扱うログの即時削除を意味しません。文字起こし・議事録の結果はアプリに返し、端末に保存します。当社の文字起こしサーバーは結果をデータベースに保存しません。ユーザが利用するiCloud同期・端末バックアップ・共有機能は別途適用されます。
  • 運用情報：サービスの運用、障害調査、不正利用防止のため、リクエスト時刻、認証情報、IPアドレス等の通信情報、処理状況、エラー、トークン使用量などをGoogle Cloud等のサービスが処理します。当社サーバーは処理状況・エラー・使用量を記録し、障害通知にSlackを利用します。AIの入力内容を広告配信のために利用する処理はありません。

本機能は請求先が有効なプロジェクトを通じて Gemini API の有料サービスを利用します。有料サービスの条件では、Google は入力と出力を製品改善に利用せず、データ処理条項に基づいて処理します。一方、安全性確保、不正利用検出、法令対応のため一定期間ログが保持される場合があります。Googleによるデータの取扱いは、Gemini API追加利用規約および適用されるデータ保護条件に従います。共有先には、本ポリシーで説明する個人データの保護と同等以上の保護を求め、利用目的の制限、機密保持、アクセス管理、安全管理、削除に関する条件を確認します。

AI transcription and meeting minutes

These features use Google's Gemini API. For AI transcription, we collect the selected recording's audio and language setting to transcribe speech, distinguish speakers and create a summary. For cloud meeting minutes, we send the transcript text and language setting to generate a summary and to-do items; this operation does not upload the audio file. Personal information within the content, including names, contact details and voices, is included and is not automatically removed.

Audio passes through Google Cloud Storage and our server on Google Cloud Run to the Gemini API. Text passes through our server to the Gemini API. Google Firebase Authentication provides an anonymous ID and token for authentication, abuse prevention and usage limits. The ID is also used in the audio storage path. We do not add this ID or advertising IDs to Gemini generation requests.

Android 2.10.0以降の録音中の文字起こしは、対応端末の端末内音声認識を使用します。非対応端末では、自動で外部の音声認識サービスへ送信しません。録音後のクラウド文字起こしには、上記の送信説明と事前同意が適用されます。

The app separately explains and requests permission for audio and transcript sharing before the corresponding cloud operation. You can allow or decline. Permission also applies to future uses of the same feature, including audio-transcription Shortcuts. You can withdraw permission for future requests using Settings > Reset AI sharing permissions; this does not recall data already sent. Earlier consent does not replace consent to the updated disclosure. Without permission, authentication for that operation, uploads and generation do not start. Recording and playback remain available. Shortcuts require prior audio-sharing consent in the app. On-device Apple Intelligence minutes stay on the device; cloud fallback requires text-sharing consent. Apple's speech recognition is separate and may send audio to Apple under the OS speech-recognition permission.

In Android 2.10.0 and later, live transcription uses on-device speech recognition on supported devices. Unsupported devices do not automatically send audio to an external speech recognition service. Cloud transcription after recording requires the disclosure and prior consent described above.

We request deletion of the Cloud Storage audio after transfer to Gemini. Remaining objects become eligible for lifecycle deletion at an age of one day; deletion is asynchronous, so completion within 24 hours is not guaranteed. Deleted objects are recoverable for seven days. We request deletion of the Gemini Files upload when processing ends. These requests do not imply immediate deletion of Google's safety logs. Results are returned to and saved by the app, not stored in a database by our transcription server. Separately used iCloud sync, device backups and sharing may also apply.

Operational data such as request times, authentication details, IP addresses, status, errors and token usage may be processed for service operation, troubleshooting and abuse prevention. Our server records status, errors and usage and uses Slack for failure notifications. AI input is not used by our implementation for advertising.

We use Gemini API Paid Services through a project with active billing. Under those terms, Google does not use inputs or outputs for product improvement and processes them under its Data Processing Addendum. Google may retain logs for safety, abuse detection and legal obligations. Google's processing is governed by the Gemini API terms and applicable data-protection terms. We require recipients to provide protection equal to or greater than that described in this policy, including purpose limitation, confidentiality, access controls, security and deletion obligations.

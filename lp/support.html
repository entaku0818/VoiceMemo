よくあるご質問

画面を閉じると録音が止まってしまいます

バックグラウンド録音に対応しているため、通常はホーム画面に戻っても録音は継続します。止まる場合は、iOS の低電力モードがオンになっていないか、他の録音アプリや通話がマイクを使用していないかをご確認ください。

録音が開始できません

設定アプリ → シンプル録音 → マイク が許可されているかご確認ください。許可がオフのままだと録音を開始できません。

WAV と AAC(M4A) はどう使い分けますか？

WAV は非圧縮で音質を最優先したい場合に、AAC(M4A) はファイルサイズを抑えたい場合に向いています。長時間録音では AAC をおすすめします。

特定の区間だけを繰り返し再生したい

AB区間リピートをご利用ください。開始点(A)と終了点(B)を指定すると、その区間だけを繰り返し再生します。再生スピードは 0.5〜2.0 倍速まで変更できるため、語学学習のシャドーイングにも活用できます。

文字起こしはどのように動作しますか？

文字起こしは Gemini AI を利用しており、処理のために音声データが外部の AI サービスへ送信されます。広告を視聴することで無料でご利用いただけるほか、プレミアムプランでは回数制限なくお使いいただけます。機密性の高い音声については、この点をご了承のうえご利用ください。

文字起こしが失敗します

通信環境をご確認ください。また、極端に長い音声や、話し声がほとんど含まれない音声では失敗することがあります。うまくいかない場合は、録音を分割してからお試しください。

iCloud 同期が反映されません

設定アプリ → ユーザー名 → iCloud で iCloud Drive がオンになっているか、端末が Wi-Fi に接続されているかをご確認ください。ファイル数が多い場合、初回の同期には時間がかかることがあります。

録音ファイルを整理したい

ファイル名の変更・並べ替えのほか、プレイリストを作成してまとめて管理できます。波形エディタで録音内容を確認しながら編集することも可能です。

機種変更しました。プレミアムを引き継ぐには？

購入時と同じ Apple ID でサインインし、アプリ内の「購入を復元」をお試しください。解約は iOS の 設定 → ユーザー名 → サブスクリプション から行えます。

録音データが消えてしまいました

アプリを削除すると端末内の録音データも削除されます。大切な録音は、共有機能で他のアプリやクラウドへ書き出すか、iCloud 同期をオンにしてお使いください。

Support (English)

Recording stops when I leave the app

Background recording is supported. If it stops, check that Low Power Mode is off and that no other app or call is using the microphone.

Recording won't start

Open Settings → Simple Voice Recorder → Microphone and make sure access is allowed.

How does transcription work?

Transcription is powered by Gemini AI, so audio is sent to an external AI service for processing. It's free with an ad, or unlimited with Premium. Please keep this in mind for sensitive recordings.

Repeating a section (A-B repeat)

Set point A and point B to loop just that segment. Playback speed is adjustable from 0.5x to 2.0x — useful for language shadowing.

Restoring Premium on a new device

Sign in with the same Apple ID and use "Restore Purchases". Manage or cancel via Settings → your name → Subscriptions.
